# 🧪 دليل الاختبار السريع

## ✅ قائمة الاختبار

### 1️⃣ اختبار Backend:

```bash
cd backend
npm start
```

**يجب أن ترى:**
```
✅ Database initialized successfully
🚀 Server running on port 3001
📡 Local Network: http://0.0.0.0:3001
🔐 Default Admin: username=admin, password=admin123
```

---

### 2️⃣ اختبار Frontend:

```bash
cd frontend
npm run dev
```

**يجب أن ترى:**
```
VITE v5.x.x ready in xxx ms
➜ Local: http://localhost:5173/
```

---

### 3️⃣ اختبار تسجيل دخول Admin:

1. افتح: `http://localhost:5173/admin`
2. أدخل:
   - Username: `admin`
   - Password: `admin123`
3. **النتيجة المتوقعة**: دخول لوحة التحكم

---

### 4️⃣ اختبار إضافة مستخدم:

1. في Admin Panel، اضغط "Add User"
2. أدخل:
   - Username: `test`
   - Password: `test123`
   - Role: `User`
3. اضغط "Create User"
4. **النتيجة المتوقعة**: رسالة نجاح + ظهور المستخدم في القائمة

---

### 5️⃣ اختبار تسجيل دخول مستخدم:

1. افتح: `http://localhost:5173`
2. أدخل:
   - Username: `test`
   - Password: `test123`
3. **النتيجة المتوقعة**: دخول واجهة المحادثة

---

### 6️⃣ اختبار إنشاء مجموعة:

1. في Admin Panel، اذهب لتبويب "Groups"
2. اضغط "Add Group"
3. أدخل:
   - Group Name: `Test Group`
   - اختر المستخدم `test`
4. اضغط "Create Group"
5. **النتيجة المتوقعة**: ظهور المجموعة في القائمة

---

### 7️⃣ اختبار إرسال رسالة:

1. سجل دخول كمستخدم `test`
2. اختر "Test Group" من القائمة
3. اكتب رسالة واضغط Enter
4. **النتيجة المتوقعة**: ظهور الرسالة في المحادثة

---

### 8️⃣ اختبار تعطيل مستخدم:

1. في Admin Panel، اذهب لتبويب "Users"
2. اضغط على أيقونة 🚫 بجانب المستخدم `test`
3. **النتيجة المتوقعة**: 
   - تغيير حالة المستخدم إلى "suspended"
   - المستخدم يتم فصله تلقائياً

---

### 9️⃣ اختبار تغيير كلمة المرور:

1. في Admin Panel، اضغط على أيقونة 🔑 بجانب المستخدم
2. أدخل كلمة مرور جديدة: `newpass123`
3. اضغط "Save"
4. حاول تسجيل الدخول بكلمة المرور الجديدة
5. **النتيجة المتوقعة**: تسجيل دخول ناجح

---

### 🔟 اختبار سجل النشاطات:

1. في Admin Panel، اذهب لتبويب "Activity Logs"
2. **النتيجة المتوقعة**: رؤية جميع الأحداث السابقة مع التوقيت

---

## 🐛 إذا واجهت مشاكل:

### Backend لا يعمل:
```bash
# تحقق من المنفذ
netstat -ano | findstr :3001

# أعد تثبيت المكتبات
cd backend
rm -rf node_modules package-lock.json
npm install
```

### Frontend لا يعمل:
```bash
# أعد تثبيت المكتبات
cd frontend
rm -rf node_modules package-lock.json
npm install
```

### قاعدة البيانات تالفة:
```bash
# احذف قاعدة البيانات (ستُنشأ من جديد)
cd backend
del lan-chat.db
npm start
```

## 📊 اختبار الشبكة المحلية:

### على جهاز آخر:

1. اعرف IP جهاز السيرفر:
   ```bash
   ipconfig
   ```

2. على الجهاز الآخر، افتح:
   ```
   http://YOUR_IP:5173
   ```

3. سجل دخول بحساب مستخدم

4. أرسل رسالة

5. **النتيجة المتوقعة**: الرسالة تظهر على جميع الأجهزة المتصلة
